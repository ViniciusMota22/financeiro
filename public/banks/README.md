# Logos dos bancos

Os PNGs desta pasta foram obtidos de `logos-bancos-br` (`https://github.com/rzmt/logos-bancos-br`) em 25/09/2026 usando o caminho público `https://cdn.jsdelivr.net/npm/logos-bancos-br@0/logos/png/{ISPB}.png`. Eles são exibidos apenas para identificar a instituição nos cartões; não indicam parceria ou endosso. As marcas pertencem aos respectivos titulares e não fazem parte da licença MIT do projeto de origem. Veja o aviso de marcas em `https://github.com/rzmt/logos-bancos-br/blob/main/DISCLAIMER.md`.

O arquivo informado para Neon (`12831352.png`) respondeu HTTP 404 e não foi incluído. O app usa um ícone genérico para Neon e para qualquer banco sem logo verificado.
